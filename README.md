# ScribeForge Website

Premium content at startup speed — the official ScribeForge website.

## Pages
- `index.html` — Home / Landing page
- `services.html` — Services & Pricing
- `agencies.html` — White-Label Agency Partnerships
- `contact.html` — Contact & Inquiry form

## Tech
Pure HTML + CSS (no build tools). Hostable on any static host (GitHub Pages, Vercel, Netlify, etc.).

## Local dev
Open any `.html` file directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```
